# CSS Basics and Multimedia Assignment

## About
This is a beginner-level web development assignment created to practice basic CSS styling and HTML multimedia elements.

## Topics Covered
- Background colors
- Font sizes and text styling
- Inline CSS
- Internal CSS
- External CSS
- HTML audio element
- HTML video element

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Understand different ways to apply CSS.
- Practice basic webpage styling.
- Learn how to embed audio and video in a webpage.

## Purpose
This project was created as part of my university coursework to improve my HTML and CSS skills.# CSS-basics-audio-video
A beginner-friendly web development assignment covering CSS basics, background colors, font sizes, inline, internal and external CSS, along with HTML audio and video elements.
